# Sandeep K. Tripathi Personal Brand Website

A premium, responsive personal-brand website for an astrologer, numerologist, and Astro-Vastu consultant specializing in business, finance, and industrial growth.

## Run locally

Open `index.html` in a browser, or serve the folder with a static server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
